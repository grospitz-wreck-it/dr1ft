# DR1FT Master Context

## Purpose

This document defines the immutable principles of the DR1FT project.

It is **not** an implementation guide, coding standard, API reference or feature specification.

Instead, it serves as the constitutional foundation of the project and provides the conceptual framework that every contributor—human or AI—must follow.

Whenever uncertainty arises, this document has precedence over all other project documentation.

# Project Identity

## Project Name

**DR1FT**

## Vision

DR1FT is an AI-first educational platform that teaches digital media literacy through interactive experiences inside a simulated social media ecosystem.

Rather than telling players what manipulation looks like, DR1FT allows them to experience manipulation firsthand in a safe environment where every interaction becomes an opportunity for reflection and learning.

## Mission

The mission of DR1FT is to strengthen digital resilience by enabling users to recognize manipulation before encountering it in real life.

Instead of teaching facts, DR1FT teaches competencies.

Instead of providing answers, DR1FT encourages reflection.
